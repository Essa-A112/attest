# IT Security Policy

This policy protects company systems and information from misuse and attack.

Staff must use the company password manager for all work accounts and must never reuse a password across systems.
Multi-factor authentication must be enabled on every system that supports it.
USB storage devices must never be used to store or transfer customer data.
Software must only be installed from the approved application catalogue; requests for other software go to IT.
Suspected phishing emails must be reported using the report button in the mail client, not forwarded to colleagues.
Security incidents, including lost devices, must be reported to the IT security team within 4 hours.
Laptops must be encrypted and must never be left unattended in vehicles.
Administrative access must only be used for the specific task that requires it, then relinquished.
